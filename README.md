# Portfólio de Daniel

Site em português brasileiro adaptado a partir do README enviado.

## Arquivos
- `index.html`: página principal
- `portfolio-details.html`: contribuições
- `service-details.html`: áreas de atuação
- `starter-page.html`: página complementar

Abra `index.html` no navegador. O Bootstrap é carregado via CDN e requer internet.

O README não informa links válidos para todas as redes sociais nem percentuais de habilidades. Por isso, essas informações não foram inventadas.
